Co się zmieniło w aplikacji — najnowsze na górze. Opisuję zmiany z punktu widzenia
osoby, która z niej korzysta, a nie z punktu widzenia kodu.

Aktualizacje obrazu, w tym zmiany wymuszone przez API Allegro, są częścią abonamentu.

:::caution[Do uzupełnienia]
Pierwszy wpis dodajemy przy pierwszym wydaniu u klienta. Format:

```markdown
## 2026-08-01 · wersja 1.1

- **Nowe:** krótki opis tego, co użytkownik zobaczy
- **Poprawione:** co przestało sprawiać problem
- **Uwaga:** czy coś wymaga działania po Twojej stronie
```
:::
